# React Native Mock Interviews

React Native interviews are often harder than they need to be. Most candidates do not fail because they cannot learn the material. They fail because they have not had enough realistic practice explaining their decisions, tradeoffs, and debugging approach under pressure.

This project exists to make that practice public, structured, and reusable.

## What this project is

- A community-driven archive of React Native mock interviews
- A learning-first interview format where candidates receive questions in advance
- A public knowledge base for React Native fundamentals, architecture, performance, native integration, testing, and career growth
- A TechCraft By Subrata initiative focused on helping developers become industry-ready

## What makes it different

Most interview-prep repositories stop at a question list. This project goes further by collecting:

- Candidate background and target level
- Interview question sets
- Discussion notes and reasoning
- Constructive feedback
- Improvement areas
- Learning resources
- Interview recordings published on the [TechCraft Club YouTube channel](https://www.youtube.com/@techcraftclub)

The objective is not evaluation. The objective is deeper understanding and clearer technical communication.

## Participation expectations

- Showing your face is optional
- The session is for helping the community, not simulating a hostile real interview
- Volunteers may share a resume if they want to provide more context, but it is not required

## Core topics

- React Native fundamentals
- JavaScript and TypeScript
- State management
- Mobile architecture
- Performance optimization
- Native modules and platform work
- Testing and debugging
- Offline-first design
- AI in mobile applications
- Career and communication skills

## Who this is for

- Developers preparing for React Native interviews
- Engineers who want realistic architecture and debugging discussions
- Community volunteers who want to share experience publicly
- Hiring managers or mentors building better interview loops

## Current state

The repository is still early. The website now reflects the actual project direction, while the content archive will grow as more mock interviews and supporting notes are added.
