# Contributing

This project is open to contributors who want to improve the quality of React Native interview preparation.

## Ways to contribute

- Improve question quality
- Refine answers or explanations
- Add learning resources
- Report outdated content
- Volunteer for a mock interview
- Help structure completed interview archives

## Volunteer participation

- Completed interviews are intended for publication on the [TechCraft Club YouTube channel](https://www.youtube.com/@techcraftclub)
- Showing face is optional because the goal is community learning, not interview pressure
- Resume sharing is optional and should only happen with the volunteer's consent

## Contribution standards

- Keep content practical and technically defensible
- Prefer real-world scenarios over trivia
- Match the question difficulty to the candidate level
- Be respectful in feedback
- Optimize for learning, not gatekeeping

## GitHub workflow

1. Create or update content in the repository.
2. Preview the docs site locally from `docs-site/`.
3. Open a pull request with a clear summary of what changed.

## Local development

```bash
cd docs-site
npm install
npm start
```
