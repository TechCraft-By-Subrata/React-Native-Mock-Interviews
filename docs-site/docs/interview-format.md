# Interview Format

Each mock interview is designed as a structured learning session, not a surprise test.

## Principles

- Candidates receive the question set in advance
- Preparation is encouraged
- Discussion quality matters more than speed
- Feedback is practical and specific
- The output should help future learners too
- Showing face on video is optional
- Resume sharing is optional

## Typical flow

| Section | Duration |
| --- | --- |
| Introduction | 5 mins |
| React Native Fundamentals | 20 mins |
| JavaScript and TypeScript | 15 mins |
| Architecture Discussion | 20 mins |
| Coding and Debugging | 20 mins |
| Performance Optimization | 15 mins |
| Q&A and Feedback | 15 mins |

## What each interview should contain

- Candidate background
- Calibrated question set
- Discussion notes or answers
- Feedback and improvement areas
- References for deeper study
- Recording link on the [TechCraft Club YouTube channel](https://www.youtube.com/@techcraftclub)

## Recording policy

- Interviews are intended to be uploaded publicly on the TechCraft Club YouTube channel
- Volunteers can choose whether to appear on camera
- The format is community-help oriented, not pressure oriented
- A volunteer may share a resume for context if they are comfortable doing so

## Calibration

Question sets should reflect the candidate's actual experience level. A 2-year React Native engineer and a 7-year cross-platform architect should not receive the same interview bar.
