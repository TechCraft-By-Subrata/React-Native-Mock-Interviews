## 🚀 About This Repository

Technical interviews can be intimidating, especially when you don't know what to expect.

This repository is a collection of **React Native mock interview experiences** conducted under the **TechCraft By Subrata** initiative.

Unlike traditional interviews, participants receive the question set **before the interview** so they can prepare thoroughly and focus on explaining concepts clearly. The objective is **learning**, not evaluation.

Every interview contributes to a growing knowledge base that helps developers understand:

* React Native fundamentals
* Mobile architecture
* Performance optimization
* Native modules
* State management
* Navigation
* Debugging
* System design
* Offline-first applications
* AI in React Native
* Real-world project discussions
* Coding best practices
* Career guidance

Whether you're a fresher or an experienced engineer, you'll find practical insights from developers with different backgrounds and experience levels.

# 🎯 Mission

Our goal is simple:

> **Make high-quality React Native interview preparation freely accessible to everyone.**

Instead of memorizing answers, we encourage developers to understand concepts deeply and communicate them confidently.
